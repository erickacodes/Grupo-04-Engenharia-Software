# 💻 Grupo 04 – Engenharia de Software

Bem-vindo ao repositório oficial do **Grupo 04**.

Este repositório foi criado para centralizar os projetos, atividades, trabalhos e estudos desenvolvidos ao longo do curso de **Engenharia de Software**.

---

## 📂 Objetivo

- Organizar os projetos acadêmicos do grupo;
- Facilitar a colaboração entre os integrantes;
- Controlar versões utilizando **Git** e **GitHub**;
- Manter um histórico da evolução dos trabalhos.

---

## 📁 Estrutura

Cada projeto será organizado em sua própria pasta, contendo seu código-fonte, documentação e demais arquivos necessários.

---

## 🛠 Tecnologias

Ao longo do curso iremos utilizar e aprofundar nossos conhecimentos das seguintes tecnologias:

* C
* Java
* JavaScript
* HTML
* CSS
* Git
* GitHub
* Banco de Dados
* Engenharia de Software
* Metodologias Ágeis

---

## 🤝 Colaboração

Todos os integrantes do **Grupo 04** contribuem para este repositório seguindo boas práticas de organização, documentação e versionamento.

Antes de enviar alterações, recomenda-se:

* Criar uma branch para a nova funcionalidade ou correção;
* Escrever mensagens de commit claras e objetivas;
* Revisar o código antes de realizar o merge.

---

## 📌 Organização

Os projetos serão adicionados conforme o andamento das disciplinas, mantendo uma estrutura organizada e de fácil navegação para todos os integrantes.
